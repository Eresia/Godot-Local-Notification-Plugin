# Godot Local Notification Plugin

This Godot Android plugin can be used to get notification from a websocket local server.

You can follow [these instructions](https://docs.godotengine.org/en/stable/tutorials/platform/android/android_plugin.html) to build et install the plugin on your project. You can check the project on plugin/demo/project.godot to have an example of how use the plugin (check [plugin/demo/scripts/main.gd](plugin/demo/scripts/main.gd))
